# 系统测试策略与质量保障

系统测试体系覆盖 Worker 控制面、Go Agent、静态分发 Worker、前端 Web 界面及端到端容量验证。运行命令详见 [README](../README.md#校验)。

## 1. Worker 控制面测试

Worker 测试套件位于 `apps/worker/test`，在 Vitest Workers 池环境下运行，每个测试套件在执行前应用真实的 D1 迁移脚本：

- 订阅渲染与格式化：验证 Clash.Meta YAML 解析有效性、代理组与规则结构；验证通用 URI 规范、IPv6 编码及 Base64 转换。
- 访问控制与凭据生命周期：覆盖 Token 轮换与撤销、到期检测、配额超限阻断及空可用节点时的 503 保护。
- 节点状态派生：测试在线、降级、离线与停用状态的动态判定逻辑。
- 流量上报幂等性：验证重复 `report_id` 入账、同 ID 载荷冲突识别、心跳优先落盘机制与跨自然小时数据校验。
- 凭据同步与 ETag：验证用户拉取端点的 `ETag` 机制，校验 `If-None-Match` 命中 304 及版本变更后的增量返回。
- 定时任务与数据保留：验证每 15 分钟的用户计费周期滚动，以及每日凌晨的历史用量批量物理清理。
- 权限隔离体系：覆盖 Access 身份认证及管理员角色授权边界。

## 2. Go Agent 节点端测试

Agent 测试位于 `apps/agent`，使用临时内存数据库与环回 gRPC Mock 服务，运行过程无需真实 Xray 核心、root 特权或外网环境：

- 采样与基线计算：覆盖首次采样基准建立、常规增量计算、计数器清零与进程重启场景下的断层标记。
- 报表批次切分：测试小时自然桶切分逻辑与 40 用户上限拆分逻辑，确保排除本地管理 API 的流量干扰。
- 队列容错与退避：验证服务端确认移除报表机制、409 冲突报表淘汰、429 重试等待及网络超时指数退避算法。
- 凭据同步与热更新：测试首次应用落盘、用户集合差集计算（增、删、改）、HandlerService 协议编解码，以及热更新失败时自动回退为配置重启与健康检查的完整流程。
- 配置合入与原子替换：验证只替换入站凭据、注入本地私钥及配置语法校验逻辑。

## 3. 分发与打包测试

- 发布包校验（`deploy/tests/package-release.sh`）：验证压缩包目录结构、必要服务单元文件、polkit 规则、版本注入标识及敏感文件排除。
- 分发准备校验（`deploy/tests/stage-downloads.sh`）：验证分发清单、`SHA256SUMS` 哈希值、版本号一致性及静态安全标头。

## 4. 前端与端到端联调

- 静态类型与编译检查：运行 `npm run typecheck` 结合 `vue-tsc` 与 `vite build` 确保前端构建完整。
- 容量与压力基准（`npm run capacity`）：在本地隔离 D1 环境中模拟 100 节点、100 用户组合及 500 条分流规则的高负载场景，度量订阅渲染与管理接口在 p95 延迟与 CPU 执行开销方面的表现。
- 实体节点联调：在 Debian 12 与 Debian 13 环境中验证一键安装脚本执行完整性，确认服务仅绑定本地环回端口并能正确热更新代理凭据。
